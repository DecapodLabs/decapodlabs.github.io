## 1. Mission and success criteria

Demonstrate the following lifecycle using an actual autonomous coding agent:

1. A human supplies one natural-language engineering objective.
2. The agent independently discovers and uses Decapod.
3. The agent encounters a genuinely failing required validation.
4. Decapod rejects the work and provides actionable evidence.
5. The agent diagnoses the failure without a human supplying the repair.
6. The agent implements the correction.
7. Decapod executes the required checks and produces fresh evidence.
8. The agent publishes a real GitHub pull request through Decapod.
9. Independent readback confirms the PR matches the validated artifact.
10. Stale evidence, source mutation, and target-base advancement cannot authorize the wrong artifact.

The result must be demonstrably autonomous.

The implementation should then produce a professionally edited launch film using the actual execution events and Decapod's existing visual identity.

**Definition of done:** A real autonomous run, correct rejection and recovery behavior, verifiable evidence, completed video assets, website integration, passing required validation, and published implementation PRs.

A deterministic mock is useful for regression testing. It cannot substitute for the real-agent acceptance demonstration.

The agent must independently consult Decapod, establish appropriate task/workspace state, investigate a real failure, repair the code, obtain validation, and publish the PR.

### Publication and adversarial validation

Demonstrate:

- Failed work cannot earn admission.
- Successful repair requires new evidence.
- The evidence identifies the exact validated source.
- Mutating source invalidates applicable historical proof.
- Advancing the accepted target invalidates base-bound proof.
- The actual published PR matches the validated head.
- Post-creation proof failure produces a truthful non-admission result.
- PR admission never implies merge authorization.

Perform independent GitHub readback.

Archive both successful and failed attempts without rewriting historical records.

If a real agent bypasses Decapod, preserve the result and identify the exact boundary that failed. Do not artificially force the demonstration green by weakening governance.
