# Local + Cloud commercial offerings

Decapod Local is free, offline, and requires no signup; Get started links to `https://decapodlabs.github.io/decapod/quickstart.html`. Decapod Cloud is published on `/pricing` at $50 per contributor per repository per month ($552 annual upfront with approved annual and volume discounts) alongside the compiled static web presentation bundle built from `DecapodLabs/propodus`.

This supersedes the earlier pre-launch withholding proposal. Public marketing and compiled static UI presentation live in this repository; identity, billing, entitlement, and backend state remain exclusively within the Cloud backend service.
