# First-use review protocol

Start with the [content recovery inventory](content-recovery-103.md) and the active [positioning contract](positioning-and-design-contract.md). Account for the evidence levels independently. An expert walkthrough measures the presented information and interaction. Only a genuine participant session establishes how an unfamiliar reader understood it.

## Local journey

> You maintain a repository with coding agents. A colleague recommends Decapod. Work out what it does, how you would try it, and what to expect when you request a small feature.

- What would you delegate, and to which agent?
- What does Decapod give the agent before and during work?
- What continues without you if the first implementation fails a check?
- What project knowledge or work record can a later session recover?
- When is a human decision necessary? What can you inspect to learn what was delivered?

Follow the page from hero through the operating model and capability examples, then use the Quickstart. A request that begins as a feature observes the ordinary path; a recoverable failure observes continuation without a new product decision.

## Cloud and publication

> You are joining a configured repository. Work out which steps belong to the administrator, which you may need at sign-in, and how you would see the result of the work you requested.

Use a separately authorized hosted fixture for authenticated work. Confirm the real permission boundary, the artifact or endpoint reached, and the applicable checks and unresolved dependencies. For a public browsing walkthrough, stop before live Signup authorization, financial actions, or account access.

## Review record

Record exact revision, viewport, source or live destination, answers documented by the observer, and the origin of each observation. For browser interaction, check readability, focus, navigation, playback controls, and pinned-footer clearance at representative desktop and mobile widths. Record technical blockers separately from product-learning observations. No external participant results are claimed in this revision.
