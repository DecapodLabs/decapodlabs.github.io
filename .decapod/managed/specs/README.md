# Project specifications

These living specifications describe the Decapod Labs homepage, public Cloud-first pricing, and static presentation distribution for Decapod Cloud. Local is free forever without signup; Cloud pricing and purchasing entry are live on `/pricing` with interactive Signup and Admin presentation bundles compiled from upstream commercial sources.

INTENT describes the current public contract; ARCHITECTURE and INTERFACES describe static presentation boundaries and navigation; SECURITY, VALIDATION and OPERATIONS distinguish static site verification from backend payment and authorization services.
